# 스크린 원장 (append-only)

> 규칙은 `docs/screen_protocol.md`. 행은 덧붙이기만 한다 — 고치지 않고, 틀린 행은 정정 행을 덧붙인다.
> **스크린 결과는 매매 근거가 아니다.** S 행은 가족의 k에 들어가고, M 행(측정)은 어떤 k에도 N에도 들어가지 않는다.
> 스크린마다 자료를 읽기 **전에** START 행을, 끝난 뒤 RESULT 행을 덧붙인다.
