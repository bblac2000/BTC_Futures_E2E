# 시행 레지스트리 (append-only)

> 규칙: 삭제·수정 금지, 추가만. 틀린 행은 고치지 않고 정정 행을 덧붙인다(행 번호 인용).
> 파라미터·임계 변경 = 새 행 + 새 사전등록. 실패 후보 이름 바꿔 재제안 금지(research-protocol §4·§7).
> 판정 3분류 ACCEPT / REJECT / 폐기 · 기각은 검정력 부족 vs 효과 부재를 구분한다.
