## 0. 가설 (한 문장 · 암별)
**BTCUSDT 1m mark의 30분 로그수익률이 후행 90일 분포의 0.5% 꼬리를 넘는 플러시가 미결제약정(OI) 감소와 함께 일어난 뒤, 변동성이 식은 시점에 플러시의 반대 방향으로 4시간 보유하면 비용(왕복 22 bps 보수 모델)·펀딩 차감 뒤 트레이드당 순엣지가 양(+)이다.**
- **Arm L(판정 대상)**: DOWN 플러시(r30 ≤ q_dn) 뒤 **롱**.
- **Arm S(판정 대상)**: UP 플러시(r30 ≥ q_up) 뒤 **숏**.
- 두 암은 **각각 독립 가설이자 독립 장부**다(진입 조건이 반대라 중첩되지 않는다 · 트라이얼 #1·#2의 "판정 A + 보고 B"와 다르다). 트라이얼 결과 = 두 암의 판정 쌍.
- 원천 관찰(공개 · 한계): arXiv:2608.03616(단독 저자 · 피어리뷰 전)은 대형 청산 연쇄에서 강제 매도가 30분 안에 몰린다는 **구조 관찰**을 보고한다. **바이낸스에서 되돌림 알파가 있다는 증거가 아니다** — 이 가설은 그 관찰에서 파생한 우리 가설이고 논문 수치를 임계로 차용하지 않는다.
- **N 카운터 = 6(누적 · 헌법 v1.3 research-protocol §5)**: 같은 IS 자료 위 시도 = 트라이얼 #1(A·B) + #2(A·B) + #3(L·S). 트라이얼 #3은 #1·#2 결과를 본 뒤 고른 새 가설 둘이라 "N 무증가"(동일 가설의 전진 검증)에 해당하지 않는다. **Bonferroni α = 0.05/6 = 0.008333** · 모든 CI = **가운데 99.1667%**(하한 0.41667 · 상한 99.58333 백분위) · G-B의 SR* = 정의된 SR̂(최대 여섯) · MDE는 α = 0.008333.

## 2. 비용 모델 (G2 입력)
- **등록 비용 = 왕복 22 bps(명목)** = taker 5 bps × 2 + **슬리피지 6 bps × 2** + 실제 펀딩. 슬리피지는 체결 기준가 대비 불리 방향 + 불리 tick 반올림(레지스트리 #7 모델의 매개변수만 2 → 6 bps) — 진입·청산 **두 체결 모두**, 사이징·실행·P1·G2 전부 같은 모델.
- 근거(공개): 플러시 뒤 슬리피지는 **실측되지 않았다**(v0.2 M-3). 평시 페이퍼 모델(#7 · 2 bps/측)의 **×3을 보수 배수로 사전확약**한다 [PROPOSED §12-6]. 실측 재보정(e2e_ro)은 이 트라이얼에서 하지 않는다(재보정은 새 트라이얼).
- **꼬리표**: "2026-09 페이퍼 레짐 · taker VIP0(#36 스냅샷 0.0005) · BTCUSDT · 플러시 후 보수 슬리피지 ×3 · 재평가로 값이 바뀌어도 판정을 소급 재개봉하지 않는다".
- **비용 민감도 격자(보고 전용 · 헌법 v1.3 판정기 요구)**: 원판 트레이드당 net 엣지를 수수료+슬리피지 ×0.5 · ×1.0 · ×1.5로(펀딩은 그대로) — 어떤 격자 값도 등록 비용(×1.0 = 22 bps)을 대신하지 않는다.
- 손익분기: 진입 뒤 되돌림이 22 bps + 펀딩을 넘어야 순이익. 트라이얼 #2 L6("총 이동 ≈ 비용")을 이 가설이 넘는다는 **사전 근거는 없다** — 보유시간 분포·청산 사유 분포·연도별 결과를 반드시 보고한다.

## 3. 게이트 (암마다 · 평가 순서 고정)
> 두 암(L·S)이 각각 판정 대상이다. 한 암의 결과는 다른 암의 판정에 쓰이지 않는다(IS를 통과한 암은 다른 암과 무관하게 자기 OOS로 — 사용자 승인).
> 평가 순서(트라이얼 #2와 같은 운용): **IS 단계**(G0 → G1 → G2 → G-B → flat → 생존 → P1 → P2 → P3) → **OOS 단계**(G3 · OOS G0 · OOS 생존) → **전진 단계**(G-F). OOS는 IS 전부 통과한 암만, 한 번만.

### 3-1. 판정기 정의(두 구현이 같은 판정을 내도록)
- **CI**: 일 블록 퍼센타일 부트스트랩의 가운데 99.1667% — 하한 0.41667 · 상한 99.58333 백분위(numpy 선형) · 재표본 10,000 · 거래 0건 재표본은 빼고 개수 보고 · 스트림 `SeedSequence((20260929, 1)).spawn(8)[k]`: IS k 0 gross_L · 1 net_L · 2 gross_S · 3 net_S · OOS k 4 gross_L · 5 net_L · 6 gross_S · 7 net_S.
- **트레이드 값**: net_bps = §1 통계 원장 · gross_bps = mark 대 mark(진입 기준 mark = 체결 봉 mark 시가 · 청산 기준 mark = SL 체결 기준(min/max(SL, 시가)) · time_exit 시가 · 청산은 추정 청산가).
- **날 집합 V(암별 동일 정의)**: 창 안의 UTC 날 d 중 d가 완전한 mark 날 ∧ 그날 00/08/16 펀딩 3건 검증 ∧ 그날 분위수 유효(§1). 부트스트랩 블록 = V의 날(거래 없는 날은 빈 블록 · 무효일은 제외). 진입일이 V 밖인 트레이드는 판정기가 거부(판정 가능 구간 규칙상 생기지 않는다).
- **P1 p95** = 성공 추출의 트레이드당 평균 net_bps의 numpy 선형 95% 분위수 · **P2·P3 값** = 변형 실행의 트레이드당 평균 net_bps(0건이면 0).
- **MDE** = `(z_{1−0.008333} + z_{0.8}) · σ(net, ddof 1) / √n_eff`(G0와 같은 n_eff) · z_{0.991667} ≈ 2.3940.
- **퇴화 통계**: ρ̂ 정의 안 됨 → 0 · SR̂·PSR 정의 안 됨 → G-B 실패 · CI 정의 안 됨 → 그 게이트 실패 · MDE 정의 안 됨 → 검정력 부족 · Sharpe 정의 안 됨 → 매수보유 "비교 불가" · 정의 안 된 값을 통과로 읽지 않는다 · float64 계산이 실제로 넘치면 판정 거부(값 크기 거부 없음 · 트라이얼 #2 규약 29).
- **판정 문자열(한 줄 · 헌법 v1.3)**: 암마다 `<ACCEPT|REJECT|폐기>(§7-2: <분류>) · 생존 <통과|실패>` · 트라이얼 문자열 = `L: … | S: …`.
